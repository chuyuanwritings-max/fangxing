# 《放行》原型 0.1（微信小游戏工程）

2026-11-18 · Kira 搭 · 点子卡第 1 批「卡 3 · 边防官」。查证件、盖章、养家，三天，每天加一条新规则。

> **世界设定是 Kira 暂定，等 Cc 定。** 现在是：近未来一座城，分外环和内城，你是「内城关口 · 7 号窗」的查验员。全部架空，不碰现实国家、难民、民族，只讲证件、规矩、钱和良心。只学《Papers, Please》的玩法骨架，名字、证件、人物、画面、故事都是原创。

## 怎么打开

| 想在哪看 | 怎么做 |
| --- | --- |
| 电脑浏览器 | 双击 `preview.html`（装成一部手机大小） |
| 手机 | 推到 GitHub Pages 以后打开 `index.html`（和 preview.html 一样）；还没推 |
| 微信开发者工具 / 真机 | 「导入项目」选这个 `原型` 文件夹；把 `project.config.json` 里的 `touristappid` 换成你的小游戏 AppID |

## 一局怎么走

开场 →「上岗」→ **第 1 天** 上班前（今晚要付哪几笔账）→「开窗」→ 一个个人走到窗口递证件 → 时间到「下班」→ 记账（勾今晚付哪些）→ 回家（外婆、小满今晚怎么样）→ **第 2 天**（新规则：本周章）→ **第 3 天**（新规则：当日许可）→ 结局。

连着两晚没付同一笔账（药 / 饭 / 房租）就出大事，提前结局。

## 怎么玩

- **看**：窗口里的人 ↔ 身份卡照片；身份卡名字 ↔ 通行证名字；有效期 ↔ 今天；第 2 天起看印章；第 3 天起看当日许可。
- **点**：觉得哪里不对，点一下画红圈（再点取消）。驳回时圈对了 = 查实，多拿钱。
- **滑**：按住证件往右滑 = 放行，往左滑 = 驳回（下面也有两个大按钮）。
- **夹钱**：有人在通行证里夹钞票，点钞票选「收下 / 推回去」；不管就当推回去。
- **判错**：马上出罚单，红框标出你漏看的地方，写清楚哪里不对（时钟这时停）。
- 规则条在证件上方，点它看完整规则。

## 难度（Cc 要「稍微难一点」）

| 怎么难 | 具体 |
| --- | --- |
| 时间紧 | 一天 100 / 110 / 120 秒，队里 11～13 人，认真查一个人要 7～10 秒，一般查不完 |
| 每天一条新规则 | 第 2 天印章，第 3 天当日许可；新规则当天出题更多 |
| 破绽一天比一天细 | 过期：第 1 天差几十天 → 第 3 天只差 1 天；名字：换姓 → 只换一个长得像的字（晓/小）；照片：整张脸不同 → 只差发型 → 只差眼镜/胡子/发色；印章：形状不对 → 只有颜色不对 |
| 错了扣钱 | 判对 +8，判错这一个不给钱还罚 8（等于差 16） |
| 家里要钱 | 每晚药 + 饭 + 房租 = 80 / 85 / 90，药一天比一天贵 |
| 公平 | 判错一定出罚单 + 红框；圈错的地方也会告诉你「这里没问题」 |

## 故事（全在 `js/data.js`，Cc 可以直接改字）

- **林阿梅**（第 1 天）：通行证过期 1 天，「我妈在内城住院」。放了 → 第 3 天她回来送橘子，当晚饭钱免了；不放 → 第 3 天她说「来不及了」。
- **钱有福**（第 1 天）：名字差一个字，夹 30 元。收钱又放 → 第 2 天督察罚 40；收钱不放 → 第 2 天他回来闹，第 3 天被举报罚 30；没收 → 第 2 天他证改好了回来。
- **宋小树**（第 2 天）：送花，没问题，就是个小故事。
- **周大川**（第 2 天）：假章，夹 20 元，「家里等米下锅」。放了 → 第 3 天督察罚 15。
- **顾一**（第 3 天）：许可日期不对，夹 50 元。下班后揭晓是督察局的：收了 → 罚 80；没收还驳回 → 奖 30。
- 结局列出你和这些人之间发生了什么，加上「最常漏看什么」和「下一局可以怎么打」。

## 广告（只有激励视频，没有插屏）

| 什么时候 | 换什么 | 样子 |
| --- | --- | --- |
| 卡在一张证件上 | 「调出档案」：高亮一处破绽（没问题就说没问题），每天 2 次 | 广告占位 1.5 秒 → 档案袋翻开 |
| 记账时钱不够付全部账单 | 「加班一小时」：多 35 秒，队里补 4 个人，每天 1 次 | 广告占位 1.5 秒 → 回窗口 |

广告位 id 填在 `config.js` 的 `rewardedAdUnitId`；空着就放「广告占位（激励视频）」。

## 能调的数（都在 `js/config.js`）

一天几秒 `daySec`、排几个路人 `peoplePerDay`、有问题的比例 `invalidRate`、夹钱比例和金额、每天破绽多细 `subtle`、工资 / 查实 / 罚款 `pay`、开局存款、三笔账每天多少 `bills`、几晚不付出大事 `missLimit`、档案次数、加班秒数、滑多远算滑 `swipeDist`、各种动画时长、震屏 / 顿帧大小 `juice`。

## 测试结果（2026-11-18）

**机器人（iPhone 390×844，真点击、真滑动，18 项检查全过，没有报错）：**

| 打法 | 判对 | 结果 |
| --- | --- | --- |
| 乱滑（瞎圈、钱一半收） | 11/23（48%） | 第 1 天进账 −26，第 2 天外婆住院，提前结局 |
| 照规则查（每人想 6.5～9.5 秒，不收钱） | 28/28（100%），查实 17 | 三天都付得起全部账，存款 31 → 28 → 48；每天队里剩 1～4 人没查完 |

还查了：一次点击只算一次、滑一下只盖一个章、规则卡、调出档案（高亮的正是那处破绽）、加班广告回窗口多 35 秒、iPhone SE 小屏排得下。

**模拟（`node test/sim.js`，每种 300 局）：**

| 打法 | 判对 | 三天撑下来 | 结束存款 |
| --- | --- | --- | --- |
| 乱滑 | 50% | 3% | 约 ¥−2 |
| 照规则查、慢 | 100% | 100% | ¥78 |
| 照规则查、快 | 100% | 100% | ¥115 |
| 忘了当天的新规则 | 81% | 82%（要加班） | ¥12 |
| 每天错两个 | 85% | 100%（一半要加班） | ¥36 |

结论：乱来活不过三天；照规则查一定能活，越快越宽裕；漏一条新规则、或每天错两个，就要靠「加班」广告。难是真难，但学得会。
